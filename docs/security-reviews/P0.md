## 1. Phạm vi đánh giá (Attack Surface)

Toàn bộ các điểm chạm được triển khai trong Phase P0:
1. **Client Auth & Inputs:**
   - Form Đăng ký / Đăng nhập (`apps/web/src/components/auth-panel.ts`)
   - Schema Zod (`packages/shared/src/schemas/auth.ts`)
   - Cloudflare Turnstile token validation (`apps/web/src/lib/auth-service.ts`)
2. **Cổng lệnh duy nhất (Edge Function Gateway):**
   - Endpoint `supabase/functions/command/index.ts`
   - Xác thực JWT header `Authorization: Bearer <token>`
   - Giới hạn kích thước payload (32KB HTTP 413)
   - Schema validation qua Zod (`packages/shared/src/schemas/command.ts`)
   - Rate limit nguyên tử token bucket (`consume_rate_limit` RPC)
   - Khung idempotency chống replay (`command_idempotency` table)
3. **Cơ sở dữ liệu & RLS Policy:**
   - `profiles` & trigger `on_auth_user_created` (SECURITY DEFINER có `set search_path = ''`)
   - `audit_log` (Bảng nhật ký bất biến có trigger ngăn chặn UPDATE/DELETE)
   - `rate_limits` (RLS deny-by-default, chỉ thao tác qua RPC SECURITY DEFINER)
   - `feature_flags` (RLS chỉ cho phép SELECT, ngăn INSERT/UPDATE/DELETE)
   - `cheat_flags` (RLS deny-by-default, chỉ admin/service_role)
   - `command_idempotency` (RLS gắn với `user_id = auth.uid()`)
   - Test tự động pgTAP (`01_baseline_security_rls.sql`) quét toàn bộ bảng trong schema `public` để phát hiện bảng thiếu RLS
4. **Bảo mật ứng dụng Web & Trình duyệt:**
   - Header bảo mật Cloudflare Pages (`apps/web/public/_headers`): CSP chặt chẽ, `X-Content-Type-Options: nosniff`, `X-Frame-Options: DENY`, `frame-ancestors 'none'`, `Referrer-Policy: strict-origin-when-cross-origin`.
   - Client Bundle quét sạch chuỗi nhạy cảm `service_role`.
   - Git hook quét secret trước khi commit (Lefthook + `protect-secrets.mjs`).

## 2. Kiểm thử kịch bản tấn công đối kháng (Penetration Scenarios)

| Kịch bản tấn công | Cơ chế phòng thủ | Kết quả kiểm thử | Bằng chứng kiểm thử |
|---|---|---|---|
| **1. Bypass xác thực gọi Edge Function không kèm JWT** | Edge Function kiểm tra header `Authorization`, gọi `auth.getUser()`, từ chối ngay lập tức | **CHẶN (401)** | `supabase/functions/command/index.test.ts` (Test 1: "returns 401 when Authorization header is missing") |
| **2. Giả mạo payload / Schema Injection** | Validate qua Zod schema, từ chối field lạ, ép kiểu nghiêm ngặt | **CHẶN (400)** | `supabase/functions/command/index.test.ts` (Test 3: "returns 400 when body does not match schema") |
| **3. Tấn công DDoS làm nghẽn RAM bằng Request khổng lồ** | Kiểm tra `Content-Length > 32KB` và đọc stream có giới hạn | **CHẶN (413)** | `supabase/functions/command/index.test.ts` (Test 2: "returns 413 when Content-Length exceeds limit") |
| **4. Spam lệnh làm cạn kiệt tài nguyên (Flood/Bot)** | Token bucket atomic RPC (`consume_rate_limit`), tối đa 10 tokens, hồi 10 token/phút | **CHẶN (429)** | `supabase/functions/command/index.test.ts` (Test 6: "returns 429 when rate limit is exceeded") & pgTAP `02_rate_limits_and_idempotency.sql` |
| **5. Tấn công Replay / Phát lại lệnh trùng lặp** | Bảng `command_idempotency` lưu hash và kết quả, trả về `X-Cache: HIT` | **BẢO VỆ TOÀN VẸN** | `supabase/functions/command/index.test.ts` (Test 5: "returns cached result for repeated idempotency key") |
| **6. Đăng ký tài khoản không kèm CAPTCHA** | Zod `SignUpSchema` bắt buộc `turnstileToken` có độ dài tối thiểu | **CHẶN (Client + Server validation)** | `packages/shared/src/schemas/auth.test.ts` |
| **7. Thao tác trực tiếp vào DB bỏ qua RLS** | RLS bật trên 100% bảng public, không cấp quyền INSERT/UPDATE/DELETE cho `anon` hoặc `authenticated` | **CHẶN (0 rows affected / Deny)** | pgTAP `00_profiles_rls.sql`, `01_baseline_security_rls.sql` (24/24 tests pass) |
| **8. Tạo bảng mới quên bật RLS** | Test pgTAP tự động quét toàn bộ bảng trong `pg_tables` thuộc `public` | **TỰ ĐỘNG PHÁT HIỆN & BÁO LỖI CI** | Đã thử nghiệm đối kháng: tạo bảng thiếu RLS làm test FAIL, bật RLS test PASS trở lại |
| **9. Sửa đổi hoặc xóa nhật ký kiểm toán (`audit_log`)** | Trigger `trg_prevent_audit_log_modification` chặn mọi thao tác UPDATE/DELETE | **CHẶN (Exception: Modifying or deleting audit_log entries is strictly prohibited)** | `supabase/migrations/20261110060837_baseline_security_tables.sql` |
| **10. Clickjacking / Iframe Embedding** | Header `X-Frame-Options: DENY` và CSP `frame-ancestors 'none'` | **TRÌNH DUYỆT TỪ CHỐI NHÚNG** | `apps/web/tests/security-headers.test.ts` |
| **11. Lộ khóa bí mật (`service_role`) vào Client Bundle** | Vite build kiểm tra biến môi trường, CI kiểm tra `grep -R "service_role" apps/web/dist` | **KHÔNG CÓ KHÓA TRONG BUNDLE** | Lệnh kiểm tra Powershell `Select-String` và CI step `Bundle must not contain service_role` |
| **12. Vô tình commit Private Key / Token / Service Key lên Git** | Lefthook hook chạy `node scripts/protect-secrets.mjs` trên staged diffs | **COMMIT BỊ TỪ CHỐI** | Đã thử nghiệm đối kháng: commit chứa `SUPABASE_SERVICE_ROLE_KEY` bị reject |

## 3. Bảng tổng hợp phát hiện (Findings)

| STT | Phát hiện | Mức độ | Bằng chứng | Phương án khắc phục | Trạng thái |
|---|---|---|---|---|---|
| 1 | File `.env` chứa bí mật có thể vô tình bị đưa lên Git | Vừa | Quá trình dev cục bộ | Đưa `.env*` vào `.gitignore`, chỉ lưu `.env.example`, thêm pre-commit hook quét secret | **ĐÃ XỬ LÝ (T0.9)** |
| 2 | Kẻ tấn công có thể flood RPC `command` | Cao | Do Edge Function chạy public | Triển khai RPC `consume_rate_limit` token-bucket nguyên tử trong DB, trả về 429 | **ĐÃ XỬ LÝ (T0.7)** |
| 3 | Lập trình viên tạo migration mới có thể quên `ALTER TABLE ... ENABLE ROW LEVEL SECURITY` | Cao | Rủi ro quên cấu hình thủ công | Viết test pgTAP tự động quét mọi bảng trong `public` schema | **ĐÃ XỬ LÝ (T0.6)** |
| 4 | Trình duyệt có thể bị tấn công Clickjacking nếu không có header bảo vệ | Vừa | SPA client host trên CDN | Cấu hình file `_headers` với `frame-ancestors 'none'`, `X-Frame-Options: DENY` | **ĐÃ XỬ LÝ (T0.10)** |
| 5 | Hàm `SECURITY DEFINER` có nguy cơ Search Path Hijacking | Cao | Tiêu chuẩn Postgres | Mọi hàm `SECURITY DEFINER` bắt buộc có `SET search_path = ''` và gọi tên hàm/bảng đầy đủ với prefix schema | **ĐÃ XỬ LÝ (T0.5 - T0.7)** |
